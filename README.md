# 💰 Kathy-Financ

O **Kathy-Financ** é um aplicativo moderno e intuitivo voltado para a **gestão financeira pessoal e análise de score de crédito**. Ele foi desenhado para ajudar você a assumir o controle total das suas finanças, permitindo o planejamento de metas e o acompanhamento detalhado de receitas e despesas.

---

## 🚀 Funcionalidades Principais

*   **Gestão de Receitas e Despesas**: Monitore seus ganhos e gastos em tempo real, divididos por categorias.
*   **Análise de Score de Crédito**: Acompanhe a saúde do seu perfil financeiro baseado nas diretrizes do Banco Central (Bacen).
*   **Planejamento e Metas**: Defina objetivos financeiros de curto, médio e longo prazo e acompanhe o progresso das suas conquistas.
*   **Integração com IA (Copilot)**: Use assistentes inteligentes para obter dicas de economia e responder a dúvidas financeiras direto no app.

---

## 🛠️ Tecnologias Utilizadas

Este projeto está pronto para ser desenvolvido utilizando as melhores práticas do ecossistema de desenvolvimento:

*   **Frontend**: HTML5, CSS3 e JavaScript (opção para evoluir para frameworks como React ou Flutter).
*   **Inteligência Artificial**: Integração com GitHub Copilot para otimização de código e experiência do usuário.
